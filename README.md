# cg-taiken-gallery

オープンキャンパスCG体験講座で参加者が制作した静止画と3Dキャラクターをスマートフォン・PCのブラウザ上で鑑賞・AR撮影できるWebビューアーです。  
GitHub Pages を用いた静的ホスティング（データベース不要）で運用できます。

---

## 📁 フォルダ構成

```text
cg-taiken-gallery/
├── index.html                   # ビューアーアプリ本体
├── catalog.json                 # 講座日・作品一覧・モーション一覧の定義ファイル
├── README.md                    # 本ドキュメント（運用マニュアル）
│
├── vrm/                         # 受講生のVRMファイル置き場
│   ├── 20261122-01.vrm          # 命名規則: YYYYMMDD-作品番号.vrm
│   └── 20261122-02.vrm
│
├── png/                         # 講座時に作成した作品画像置き場
│   ├── 20261122-01.png          # 命名規則: YYYYMMDD-作品番号.png
│   └── 20261122-02.png
│
└── vrma/                        # 追加のVRMAアニメーションファイル置き場
    └── sample_motion.vrma
```

## 🚀 講座後の作品公開手順（講師向け）

### 1. ファイルの命名と配置
1. 受講生のVRMモデルを **`YYYYMMDD-作品番号.vrm`**（例：`20261122-01.vrm`）にリネームし、`vrm/` フォルダへ配置します。
2. 講座時に作成した作品画像がある場合は、同じIDで **`YYYYMMDD-作品番号.png`**（例：`20261122-01.png`）として `png/` フォルダへ配置します。
3. 追加したいVRMAモーションがある場合は、`vrma/` フォルダへ配置します。

### 2. `catalog.json` の更新
以下のどちらかの方法で `catalog.json` を更新します。

* **方法A：アプリ内の管理者画面から書き出す（おすすめ）**
  1. ビューアー右上の **「管理者」** ボタンからロックを解除します（初期パス：`vroid2026`）。
  2. 開催日・作品番号・タイトル・`.vrm` ファイルを選択して登録します。
  3. **「JSON保存」**（または「JSONコピー」）を押して `catalog.json` を出力し、リポジトリルートの `catalog.json` を上書きします。

* **方法B：`catalog.json` を直接編集する**
  `models` 配列に以下の形式で追記します。

```json
{
  "updatedAt": "2026-11-22",
  "models": [
    {
      "id": "20261122-01",
      "date": "2026-11-22",
      "number": "01",
      "title": "No.01 作品タイトル",
      "url": "./vrm/20261122-01.vrm",
      "image": "./png/20261122-01.png"
    }
  ],
  "motions": [
    {
      "id": "vrma_01",
      "name": "元気に手を振る",
      "url": "./vrma/wave_hand.vrma"
    }
  ]
}
```

### 3. GitHubへコミット＆プッシュ
`vrm/`・`png/`・`vrma/` に追加したファイルと、更新した `catalog.json` を GitHub リポジトリへアップロード（コミット＆プッシュ）すると、数十秒後に GitHub Pages へ反映されます。

## ⚠️ 運用上の注意事項（GitHub Pages 上限目安）

* **公開サイト全体の推奨容量**: 1GB 以内（VRM 1体あたり15〜20MBの場合、約40〜60体分が目安です）
* **1ファイルあたりのサイズ上限**: 100MB 未満（Webブラウザ画面からアップロードする場合は 25MB 未満）
* 容量が大きくなってきた場合は、年度や開催期ごとにリポジトリを分けて運用してください。
